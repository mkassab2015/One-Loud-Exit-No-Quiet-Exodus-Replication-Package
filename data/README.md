# Data

All files contain public registry metadata only (package names, download
counts, release timestamps); no maintainer identifiers appear anywhere.

Provided here (verification without re-collection):
- analysis_frame_rdd.parquet   - RDD analysis frame: running variable, treatment, all outcomes (n=2,697)
- panel_frame.parquet          - panel-eligible projects after late-entrant exclusion (n=2,197)
- ranking_top20k.parquet       - top 20,000 rows of the reconstructed designation ranking
- monthly_series.csv           - treated/control monthly release rates (Fig. 2 of the paper)
- event_study_coefs.csv        - event-study coefficients with 95% CIs (Fig. 3)
- robustness_grids.csv         - placebo-cutoff / donut / bandwidth / cohort grids (Sec. 4.3)
- robustness_specs_ci.csv      - the same specifications with robust CIs (Fig. 4)
- validation.json              - reconstruction validation and density-test statistics (Sec. 3.2, 3.5)
- results_rdd.json / results_panel.json / results_extended.json - headline outputs per stage
- removal_flags.parquet        - registry-removal indicator per band project (RQ4)
- late_entrants.txt            - the 500 excluded later top-N entrants

Written to Drive by a full pipeline run (large/raw; regenerated by notebooks 01-03):
- cache/state/pypi_outcomes.jsonl, cache/state/pypi_month_panel.jsonl - raw collector records
- cache/ranking_*.parquet - full reconstructed ranking
- cache/top_YYYY_MM.json  - 17 monthly top-N snapshots for the late-entrant exclusion

The mapping from each statistic in the paper to its source field is in ../MANIFEST.md.
